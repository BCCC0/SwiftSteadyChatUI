# Security

The SwiftSteadyChatUI project takes the security of its software seriously.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**
Instead, report them privately so the issue can be triaged and fixed before it
is disclosed publicly.

If you believe you have found a security vulnerability in SwiftSteadyChatUI,
please open a private security advisory via GitHub's "Report a vulnerability"
flow on the repository, or contact the maintainers directly.

We ask that you:

- Provide a clear description of the issue, including the affected version
  (tag or commit SHA) and platform.
- Include a minimal reproduction, if possible.
- Allow a reasonable amount of time for a fix to be prepared before any public
  disclosure.

We appreciate the community's help in keeping this library — and the apps that
depend on it — safe.
